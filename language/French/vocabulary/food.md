# Vocabulaire — nourriture

## Goût et texture

| Français | Tiếng Việt | Exemple |
|---|---|---|
| doux | vị nhẹ | C’est doux. |
| épicé | cay | Ce n’est pas trop épicé. |
| salé | mặn | C’est un peu salé. |
| sucré | ngọt | Le dessert est sucré. |
| chaud | nóng | La soupe est chaude. |
| froid | lạnh | Je prends un café froid. |
| léger | nhẹ bụng | Je veux un plat léger. |
| délicieux | ngon | C’est délicieux. |
| grillé | nướng | Je prends le poisson grillé. |
| frais | tươi | Les légumes sont frais. |

| un plat | một món ăn | C’est un plat vietnamien. |

## Modèles utiles

- Je voudrais **[un plat]**, s’il vous plaît.
- C’est **[doux/épicé/léger]**.
- Vous préférez **[A]** ou **[B]** ?
- Je vous conseille **[le plat]**.
