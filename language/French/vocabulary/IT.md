# Vocabulaire — informatique pratique

Dùng câu rất ngắn để tạo tương tác cơ bản. Chuyển sang English khi cần giải thích chi tiết kỹ thuật.

## Problème et action

| Français | Tiếng Việt | Exemple |
|---|---|---|
| un problème | vấn đề | Il y a un problème. |
| un risque | rủi ro | Il y a un risque important. |
| une erreur | lỗi | Nous avons une erreur. |
| une solution | giải pháp | C’est une solution simple. |
| vérifier | kiểm tra | Je vais vérifier. |
| tester | kiểm thử | Nous allons tester. |
| corriger | sửa lỗi | L’équipe va corriger le problème. |
| analyser | phân tích | Je dois analyser les logs. |
| confirmer | xác nhận | Je vais confirmer demain. |
| décider | quyết định | Nous devons décider aujourd’hui. |

## Système et livraison

| Français | Tiếng Việt | Exemple |
|---|---|---|
| les données | dữ liệu | Les données sont correctes. |
| le réseau | mạng | C’est un problème de réseau. |
| le serveur | máy chủ | Le serveur est disponible. |
| l’application | ứng dụng | L’application fonctionne. |
| la base de données | cơ sở dữ liệu | La base de données est lente. |
| les logs | log | Je regarde les logs. |
| un test | kiểm thử | Le test est terminé. |
| la version | phiên bản | C’est la nouvelle version. |
| le déploiement | triển khai | Le déploiement est terminé. |
| la mise en production | đưa lên production | La mise en production est vendredi. |
| un retour arrière | rollback | Nous avons un plan de retour arrière. |
| disponible | hoạt động/sẵn sàng | Le service est disponible. |

## Phrases réutilisables

- Je vais vérifier et je reviens vers vous. — Tôi sẽ kiểm tra và phản hồi.
- Le risque principal est **[risque]**. — Rủi ro chính là…
- Nous avons deux options. — Chúng ta có hai lựa chọn.
- Je recommande la première option. — Tôi đề xuất phương án đầu.
- Pouvez-vous donner un exemple ? — Ông/bà có thể cho ví dụ không?
- Pour les détails techniques, je peux expliquer en anglais. — Với chi tiết kỹ thuật, tôi có thể giải thích bằng tiếng Anh.

## Mini dialogue

**Manager:** Il y a un problème en production ?  
*Có vấn đề trên production à?*  
**Vous:** Oui, mais le service est disponible.  
*Vâng, nhưng dịch vụ vẫn hoạt động.*  
**Manager:** Quel est le risque ?  
*Rủi ro là gì?*  
**Vous:** Le risque principal est la performance. Je peux expliquer les détails en anglais.  
*Rủi ro chính là hiệu năng. Tôi có thể giải thích chi tiết bằng tiếng Anh.*
